# Unlock C&A

Menú principal con acceso a diferentes aventuras cooperativas:

- **Apagón en el Colegio** (`ApagonColegio/apagon.html`): misión clásica para restablecer la energía del centro educativo.
- **Módulo de Calentamiento** (`PruebaCalentamiento/prueba1.html`): tres retos breves con pistas progresivas y minijuegos interactivos para aprender la dinámica.

## Recursos comunes
- Hojas de estilo globales en `assets/css/style.css`.
- Imágenes en `assets/images/`.

Cada aventura incluye su carpeta de pistas o materiales para organizar el contenido auxiliar. El módulo de calentamiento también
cuenta con tres minijuegos (`PruebaCalentamiento/minijuegos/`) para practicar candados de colores, mensajes cifrados y candados numéricos.
